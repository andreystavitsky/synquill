# Synquill

A Flutter package for Drift-powered offline storage with automatic REST, GraphQL, and Supabase API synchronization.

## Features

- **Offline-first** data persistence with Drift.
- **Automatic two-way synchronization** with REST, GraphQL, and Supabase APIs.
- **JsonSerializable** model support.
- **Pluggable API adapters** (REST, GraphQL, and Supabase supported out-of-the-box).
- **Background sync** and retry mechanisms.
